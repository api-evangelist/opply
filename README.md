Opply is a supply chain operations platform for food and beverage brands that automates ingredient and packaging sourcing, ordering, logistics, and supplier payments. Founded in 2021 and headquartered in London, Opply draws on a database of over 1.2 million suppliers and uses AI agents overseen by F&B specialists to place and track orders, consolidate every supplier order into a single monthly invoice, and offer extended interest-free payment terms. Opply exposes a production REST API at api.opply.com spanning orders, catalog, companies, CRM, payments, agreements, onboarding, insights and recommendations, fronted by an OAuth 2.1 authorization server (RFC 8414 / RFC 9728 metadata, PKCE, dynamic client registration) and a hosted Model Context Protocol (MCP) server for agent access.

**Areas:** Company · Food and Beverage · Supply Chain · Procurement · Ordering · Payments · Sourcing · Logistics · AI Agents · MCP
