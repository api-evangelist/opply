# Opply

> Opply is a supply chain operations platform for food and beverage brands that automates ingredient and packaging sourcing, ordering, logistics, and supplier payments. It exposes a production REST API, an OAuth 2.1 authorization server, and a hosted Model Context Protocol (MCP) server for agent access.

Opply draws on a database of over 1.2 million suppliers and uses AI agents overseen by F&B specialists to place and track orders, consolidate every supplier order into a single monthly invoice, and offer extended interest-free payment terms. The API (687 paths / 910 operations, 1,045 schemas) covers orders, catalog, companies, CRM, payments, agreements, buyer onboarding, insights, and recommendations.

## Auth & discovery
- [OAuth Authorization Server Metadata (RFC 8414)](https://api.opply.com/.well-known/oauth-authorization-server): authorization_code + refresh_token, PKCE S256, dynamic client registration, 29 scopes
- [OpenID Configuration](https://api.opply.com/.well-known/openid-configuration)
- [Protected Resource Metadata (RFC 9728)](https://api.opply.com/.well-known/oauth-protected-resource): main MCP resource
- [JWKS](https://api.opply.com/.well-known/jwks.json)

## Agent access
- MCP server (hosted, OAuth-protected): https://api.opply.com/api/v1/mcp/
- Per-integration MCP endpoints: /api/v1/mcp/zendesk/, /api/v1/mcp/unleashed/
